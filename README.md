# Íris — site de apresentação

Site estático para GitHub Pages, sem instalação e sem chaves de API.

## Publicar
No repositório: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
O endereço esperado é https://matheusv09.github.io/iris-site/ — só considere publicado após a confirmação do GitHub Pages.

## Conteúdo
- `index.html`: apresentação, recursos e demonstrações locais.
- `style.css`, `app.js`, `logo.svg`: aparência e interações.
- `privacidade.html`: política do aplicativo e desta versão do site.
- `termos.html`: condições de uso e limites.

O vídeo do YouTube só carrega ao abrir o player. Os exemplos usam dados fictícios; não há captura de microfone, chat com IA ou conexão OAuth nesta página. Síntese de voz opcional depende do navegador. Nenhum segredo do aplicativo deve ser incluído neste repositório.

## Google OAuth
A publicação não equivale à aprovação do Google. Comprove o endereço no Search Console pelo método disponibilizado para sua propriedade; para o fluxo OAuth, talvez seja necessário um domínio próprio verificável. Não cadastre github.io como se fosse seu domínio. Configure a página inicial e a política com os endereços finais, depois da publicação.

A política foi confrontada com o código local em 10/11/2026. Modificações no aplicativo ou nos serviços exigem nova revisão.
